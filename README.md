\# Helpdesk TI - Monitor de tickets



Prototipo en Ionic + Angular que consume https://jsonplaceholder.typicode.com/todos

y muestra los registros como tickets de soporte.



\## Ejecutar

npm install

ionic serve



\## Funciones

\- Porcentaje de eficiencia de resolucion en la cabecera

\- Filtro por texto, estado y prioridad

\- Modal para cambiar estado y reasignar prioridad (la prioridad se maneja localmente)
